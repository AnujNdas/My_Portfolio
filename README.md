# Anuj Kumar Das — Static Portfolio

A static, multi-page portfolio built with plain HTML, CSS, and JavaScript. No React, Node.js, npm, build process, or client-side router is required.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server for local preview.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `anuj-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment URL shown in the Pages settings.

The site uses relative paths, so it works both at a GitHub project URL (`username.github.io/repository/`) and a custom domain.

## Personalize before publishing
- Replace `your-email@example.com` in `contact.html` and `assets/js/main.js`/page footers.
- Replace the LinkedIn placeholder URL in `index.html` and `contact.html`.
- Add your resume at `documents/Anuj-Kumar-Das-Resume.pdf`.
- Add actual product screenshots in `assets/images/` and update project pages/cards.
- Verify all project details, dates, and public repository links.

## Files
- `index.html`, `about.html`, `projects.html`, `contact.html`: main pages
- `projects/`: project case studies
- `assets/css/style.css`: design system and responsive styles
- `assets/js/main.js`: theme toggle, mobile navigation, footer year
- `404.html`: GitHub Pages not-found page
